What "right" means here — the target measure

GDP is revised for years, so every score must name its target. This page scores against the first release (BEA advance) — what GDPNow itself targets and what a reader expects ("what will be announced"). A second, fixed-horizon score (the value as published k quarters later) is the planned scientific default for the leaderboard; it needs later outcome vintages (ALFRED) that are not yet ingested, and recent quarters would show it only after k quarters have passed. Producers also differ in what they implicitly target — GDPNow declares the advance estimate; others don't declare — so rankings on one target can't be read as model quality alone.
